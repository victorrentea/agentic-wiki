# AI-Assisted Coding Workshop @ a bank — 2026-10-13

Two hands-on hours with IBM Bob on real tasks: what fills the context before your first prompt, driving a browser and the issue tracker from the agent, turning a session's discoveries into skills and rules, and keeping coin burn under control.

## Prompt caching

**Cached prefixes cost ≈10%, so long chats stay cheap — until the model switches.**

- **Auto-routing** answers "hi" with a cheap model, then probably sticks with it to protect the [cache](https://platform.claude.com/docs/en/build-with-claude/prompt-caching).
  - 🤖 Caches are [per model and exact-prefix](https://code.claude.com/docs/en/prompt-caching): a switch or an early edit pays full price.
- Want Opus? **Show the complexity** in a 2–4 page prompt, sent in a fresh chat. ⚓ *"trust me" fails*

## Project memory

**AGENTS.md rides on every chat: prune it each sprint, grow it after every failure.**

- Before your first prompt, the **system prompt** already holds ≈9k tokens:
  - vendor instructions, "the Bob spirit"
  - tool and MCP definitions
  - skills
  - AGENTS.md plus Bob's per-mode `.bob` rules
- No AGENTS.md? **Run `/init`**, then cut the obvious. ⚓ *`mvn clean install`*
- Before re-rolling, ask **"how do we prevent this next time?"** ⚓ *€0.50 per line*
- Daily corporate tool failures belong in **global home rules**. ⚓ *PowerShell blocked*

## Issue tracker

**Let the agent fetch the ticket and write the update back.**

- **[`gh`](https://cli.github.com) / [`glab`](https://docs.gitlab.com/cli/issue/)** fetch the issue, no MCP needed.
- Corporate route: **the internal DevOps MCP**, already wired to:
  - GitLab, Jira, SonarQube
  - ServiceNow, Confluence
- No Rally MCP yet? **[Playwright](https://playwright.dev) scrapes it**: [log in once](https://playwright.dev/docs/auth) a day. ⚓ *Rally scraped on the hallway*
- Under a day of work? **Don't think, prompt.** ⚓ *[date validation](https://github.com/victorrentea/petclinic/issues/40): two sprints vs half a day*

## MCP cost

**MCP tool descriptions ride in the system prompt every turn, so disable servers you don't use.**

- Each tool brings **[description plus parameter docs](https://modelcontextprotocol.io/specification/2025-06-18/server/tools#tool)**, like [PetClinicMcp](https://github.com/victorrentea/petclinic/blob/main/petclinic-backend/src/main/java/victor/training/petclinic/mcp/PetClinicMcp.java). ⚓ *[Grafana](https://github.com/grafana/mcp-grafana): ≈80 tools*
- **Toggle the server off** in Bob's [MCP settings](https://bob.ibm.com/docs/ide/configuration/mcp/mcp-in-bob#manage-individual-servers).
  - 🤖 Claude Code's [tool search](https://code.claude.com/docs/en/mcp#scale-with-mcp-tool-search) defers schemas, loading only names

## Skills & rules

**Skills lazy-load knowledge when their description matches. Java style belongs in a glob-scoped rule.**

- **[Progressive disclosure](https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills)**, unlike AGENTS.md → *Project memory*.
- Skill not triggering? **Lengthen its description** to 60–100 words, or force it with [`/name`](https://bob.ibm.com/docs/ide/tutorials/use-skills).
- Bob **[custom modes](https://bob.ibm.com/docs/ide/configuration/custom-modes)** scoped to a file type act as specialist personas.
  - Same idea as reviewer or architect [agents](https://code.claude.com/docs/en/sub-agents)

## Sharing skills

**Team skills live in their own Git repo, symlinked locally into every project's `.bob/skills`.**

- **Three knowledge layers**, by owner:
  - company standards, e.g. security review
  - team `<team>-ai.git`, pulled daily by cron, later a marketplace
  - personal [`~/.bob/skills`](https://bob.ibm.com/docs/ide/features/skills) ⚓ *my ADHD skill*
- [skills.sh](https://www.skills.sh/) lists \~1.3M skills, **[≈2% malicious](https://snyk.io/blog/toxicskills-malicious-ai-agent-skills-clawhub)**: scan before installing.
  - [Snyk Skill Inspector](https://labs.snyk.io/experiments/skill-scan) or [NVIDIA SkillSpector](https://github.com/nvidia/skillspector): skills ship [scripts](https://agentskills.io/specification)

## Tooling rule

**True agentic engineers never paste text: the agent fetches exactly what it needs, cheaper.**

- Don't run tests and paste: say "fix tests", it **reruns only failures**. ⚓ *human slavery*
  - Room's exception: 15-minute integration test runs
- Summarise analysis docs to markdown, then **start fresh**. ⚓ *75% SharePoint noise*
- Remote search MCPs ([Exa](https://exa.ai/mcp)) **leak your search history** outside the bank.

## Sub-agents

**Sub-agents mine low-signal sources so your conversation stays an orchestrator reading 2k-token reports.**

- Legacy code burns **200–270k tokens** before tests even run. ⚓ *people died in there*
  - [Fresh context](https://www.anthropic.com/engineering/multi-agent-research-system): no inherited traumas, but may reread files
  - Bob [spawns few by default](https://bob.ibm.com/docs/ide/features/subagents): ask explicitly

## Refinement

**Never feed a vague ticket to the agent: ask the business first.**

- Exercise: **[add pagination to owners grid](https://github.com/victorrentea/petclinic/issues/25)**, sortable, pages of 5/10/20.
- Ask **why paginate at all**, not "backend or frontend?" ⚓ *business doesn't know JSON*
  - No volume or slowness reason → don't build it
- AI ships a feature in half an hour, so **stop building for the future**: wait for the need, then ask "how many?"
- With the business in the room, paste **[Grill Me](https://skills.sh/mattpocock/skills/grilling)**: one question at a time, each with a recommended answer. ⚓ *30+ questions*
  - Plan mode is the lightweight version
- Then have it **craft a prompt** holding all the discovered complexity, and run it in a fresh session. ⚓ *enjoy a Sonnet*
- An 80-page analysis doc? **Scan it on arrival**, while it's still warm in the analyst's brain.
  - Transcribe your three amigos calls: dev, analyst, tester
  - Next level: spec-driven development, e.g. [Spec Kit](https://github.com/github/spec-kit), [OpenSpec](https://github.com/Fission-AI/OpenSpec)

## LLM wiki

**A markdown wiki mined from the code beats Confluence for agents, if a cron keeps it in sync.**

- Every new doc risks **drift**: when Confluence and code disagree, the code is the truth. ⚓ *half of Confluence is obsolete*
- One company spent ≈$10k of tokens mining its microservices, then a **weekly cron** re-merged changes with [Karpathy's LLM-wiki prompt](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f).
  - A mirror of the truth, never the source
- Served over an MCP, agents **grep markdown** far faster than they dig through Confluence pages.
