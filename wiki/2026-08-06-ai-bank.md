Two-day Agentic Engineering workshop for ≈34 developers at a bank's technology centre, run in GitHub Copilot inside VS Code. The red thread: *the agent isn't prayed to, it's educated* — and the hard work moves from code into markdown. Day 1 went from model vs harness (brain vs body) through quotas and costs, the "never leave for a break without an agent working" law, AGENTS.md as the most important file on git (the red-Ferrari preload test, anger-driven rules, scripting whatever can be scripted), skills that activate only through their description, the anatomy of a stateless conversation, CLI instead of the MCPs the bank blocks, and an OpenAPI contract that cannot drift. Day 2 covered the new stateless MCP protocol revision, Playwright's planner/generator/healer agents, grilling a vague requirement as a decision tree, OpenSpec with four files for four audiences, deterministic OpenRewrite recipes for legacy at scale, diagrams guarded by tests, "Defend the King" code review with sub-agents of another model family, and LLM guardrails placed outside the model.
