Two-day workshop (Romanian-language summary) with ≈30 engineers at a bank whose standard tooling is GitHub Copilot with prepaid AI credits, going from ghost-text and the IDE plugin all the way to agents that plan, critique and verify themselves. The red thread was *stay owner of the solution, not of the code*: build deterministic, zero-token observation points (generated diagrams, contracts, acceptance tests, Code City diffs) over the swarm of agents, keep AGENTS.md concise and earned, script every objective rule, grill the requirement before prompting, never look at agent code before another agent has reviewed it, and treat human attention (≤500 lines, ≤45 minutes, pair or mob) as the truly scarce budget. It also covered isolation levels (OS sandbox → Docker → microVM with a key-swapping proxy), approval fatigue, a production-deletion postmortem and the Gray Factory target.
