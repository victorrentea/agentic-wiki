One-day workshop with 25 engineers at a bank, working in GitHub Copilot CLI and VS Code agent mode on the petclinic repo. The morning tooled the agent up — model and effort routing, AGENTS.md as loaded-by-default memory (proved with the red-Ferrari canary), skills vs glob-bound instruction files, distributing skills through a plugin marketplace, and CLIs in place of blocked MCPs — then covered sub-agents as a context firewall and the stateless economics of a conversation. The afternoon stopped coding and started specifying: the full grilling prompt typed live, the one pivotal question in a grid feature, demanding sample rows when the agent claims it looked at the data, sizing the ceremony to the effort, and OpenSpec with a business-language proposal. Closing message: the model is almost never the bottleneck — what you never wrote down is.
