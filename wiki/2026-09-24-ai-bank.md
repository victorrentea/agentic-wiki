One-day workshop at a bank on the `petclinic` codebase: connecting the agent to company tools through vendor CLIs rather than MCP (Azure DevOps, Confluence over REST), choosing harness and model tier (including the GPT family's Sol/Terra/Luna/Astra mapping), teaching the repository through AGENTS.md, progressive disclosure, skills and a two-layer plugin marketplace, then planning a pagination feature by being grilled before writing a line of code. It brought an important update — Claude Code now reads AGENTS.md natively but skips it once a CLAUDE.md exists — plus the "agent is a genie" intent-phrasing rule, OS-level `/sandbox` vs Docker Sandboxes, the throwaway-session pattern for over-privileged CLI logins, a five-scout research recipe with an adversarial critic, the observation that stale docs let agents resurrect deleted code, and an escalation report that adds "fixes that might overfit".
