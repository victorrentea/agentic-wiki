Two-day workshop held in Romanian for a bank's team working through GitHub Copilot, on the public petclinic repo. Day 1: prepaid credit economics and harness choice (IntelliJ chat → VS Code chat → Copilot CLI), vibe coding vs engineering, skill erosion, AGENTS.md and path-scoped instructions (proven loaded with a canary), guardrail tests and git hooks, CLI-backed skills and one-plugin-per-skill marketplaces, context and cache costs, and thinking before handing a task to the agent (five warm-up questions, grill-me). Day 2: Copilot's Assisted-permissions judge vs Autopilot, gaming the Auto router, OpenSpec artefacts and their afterlife, three-amigos timing, DevEx chores for agents, adversarial code review and the human-review order (refused findings → auto-fixes → hesitations), living diagrams from traces, business-authored PRs and the shift-left of grilling to the business.
