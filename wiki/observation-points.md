Observation points are high-signal, deterministically generated views of a solution that an engineer watches — *their diffs*, not the code — to stay **owner of the solution, not of the code** once agents write it.

## Why

Once agents write the code, reading every line stops being brain-efficient: weeks of thinking are compressed into hours, and nobody keeps up line by line. But an unwatched, agent-grown solution typically collapses after the 4th–5th increment. The way out is the tower-defense picture: you don't fight every unit in the swarm below, you build towers at the chokepoints and watch what passes them. This is the main thesis of [[2026-09-07-ai-bank]], and the practical answer to [[cognitive-debt]].

## The towers

| Point | What it shows |
|---|---|
| `AGENTS.md` | The context from outside the code ([[agents-md]], [[agents-md-discipline]]). |
| Deployment diagram (draw.io) | Verified in sync with reality by a test. |
| DB schema and domain-model PlantUML | Generated from code ([[deterministic-diagrams]], [[c4-model]]). |
| Readable acceptance tests | What the system promises to do ([[acceptance-test-bdd]]). |
| API contracts | Swagger / AsyncAPI / Avro, optionally with [contract testing](https://docs.pact.io/) — regenerated so that [[drift]] breaks the build. |
| Hardware, cost limits, caches, CDN | The non-functional envelope. |
| Security | Verified by an adversarial agent, not by reading. |
| [[code-city]] diff per PR | Where the change landed, at a glance ([[review-by-images]]). |
| Sequence diagrams from traces | What actually runs ([[field-reality-diagram]]). |

## Rules

- **Zero tokens.** The views are generated by tests and scripts, not written by the LLM — a view the model drew can hallucinate (see [[c4-model]]).
- **Watch the diff.** The value is in what *changed* in a view between two commits, reviewed with the PR.
- **Protect the towers.** The guardrail files behind these points belong in CODEOWNERS at the critical tier ([[codeowners-elders]]): a failing guardrail tempts the agent to edit the guardrail instead of the code ([[reward-hacking]]). [[archunit-drift-control]] is the canonical example.
